# 📊 Qualidade de Software – Avaliação de Qualidade

## 📌 Sobre o Projeto
Repositório destinado a reunir atividade acadêmica desenvolvida na disciplina de Qualidade de Software no segundo semestre, com foco na elaboração de uma planilha com parâmetros de avaliação de qualidade de software.

O trabalho foi desenvolvido em dupla e envolveu a organização dos critérios de avaliação, análise dos parâmetros e preparação de uma apresentação para exposição do projeto ao professor.

## 📁 Atividades Desenvolvidas

- **Desenvolvimento da Planilha:** elaboração e organização de uma planilha contendo parâmetros para avaliação da qualidade de software.
- **Análise dos Parâmetros:** análise dos critérios e informações utilizados na avaliação de qualidade.
- **Elaboração de Slides:** preparação de apresentação para demonstrar e explicar o trabalho desenvolvido.
- **Apresentação do Projeto:** exposição dos resultados e explicação da planilha ao professor.

## 🛠️ Ferramentas e Conceitos
- Excel / Planilhas
- Qualidade de Software
- Parâmetros e Critérios de Avaliação
- Análise de Qualidade
- Apresentação de Projetos

## 🎯 Objetivo e Aprendizados
Compreender e aplicar conceitos de qualidade de software por meio da elaboração de critérios de avaliação, organização de informações, análise de parâmetros e apresentação dos resultados.
